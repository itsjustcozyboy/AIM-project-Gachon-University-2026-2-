# Careerfolio 구현·검증 기록

Date: 2026-10-17

## 변경

기존 진행률 중심 화면을 개인 포트폴리오로 재구성했다. 자기소개, 전공 전환, 관심, 근거가 연결된 강점, 가치·환경 가설, 마찰·미확인을 함께 표시한다. 경험은 대표 3개와 전체 9개 펼치기·분류 필터·세부 수행 내용으로 제공한다. 그래픽은 경험의 시각화이며 실제 앱 화면으로 주장하지 않는다.

6개 진로 후보에 일상 업무·경험·반대 근거·Skill/Evidence Gap·준비 부담·성장경로를 연결한다. 3개 선정 가설과 Agent 공통/차이, 원본 점수의 해석 제약, 근거 문서 링크를 제공한다. T0는 8개 자기평가를 펼쳐 보여주고 객관 숙련도와 구분한다. 기존 체크 저장·내보내기를 유지하고 내보낸 phase 상태도 체크와 일치시켰다.

공고는 서버에서 Figma·Anthropic의 공개 Greenhouse API를 조회한다. 최초/수동/활성 화면 10분 주기로 갱신하며 직무 분류·검색·Early career 키워드 필터·더 보기를 제공한다. 8초 제한·출처별 실패 분리·링크 검증·중복 제거·형식 검사를 적용했다. 실패 시 마지막 수신 결과와 그 시각을 유지하며 실패를 표시한다. 일부 실패는 성공한 기업 결과만 표시한다. 전체 채용시장·지원 가능성을 대표하지 않으며 기술 연구직도 포함된다. 국내 채용/글로벌/연구/교육은 별도 탐색 링크로 연결한다.

## 검증

- `npm run typecheck`: 통과.
- `npm run build`: 최종 프로덕션 빌드 통과. `/`, `/api/jobs`, `/api/documents` 생성 확인.
- `node tests/jobs.test.mjs`: 4개 통과. 직무 구분, 잘못된 응답, 중복/위험 링크 차단, 위치/날짜 미확인 처리.
- 실제 HTTP: `/` 200, Cross Review 문서 200, 허용하지 않은 문서 경로 404.
- 실제 `/api/jobs`: 200, Figma·Anthropic 양쪽 성공. 초기 검증 시 관련 공고 7/74건(총 81건). 수치는 해당 시점의 표본이며 고정값으로 저장/표시하지 않는다.
- Playwright Chromium 프로덕션 화면: 경험 3→9개 펼치기, 카테고리 필터, 가치관 탭, 진로→공고 필터 연결, Early career, 검색/검색 결과 없음, 경험 상세/기준선 펼치기, 체크 상태 새로고침 후 유지, JSON 다운로드 통과.
- 내보내기: 체크 해제 시 해당 phase IN PROGRESS·해당 task.done=false, Week 3 NOT STARTED·실험 빈 배열 유지 확인.
- 장애 검증: 성공 후 공고 갱신 요청을 503으로 바꿔 마지막 결과 보존·실패 문구 확인. 테스트 응답은 브라우저 검증에서만 사용하고 앱 데이터에 저장하지 않았다.
- 반응형: 320·390·768·1440px에서 문서 가로 넘침 없음. 브라우저 런타임 오류 없음. 데스크톱·모바일 전체 화면을 캡처해 시각 확인.
- 개인 Dataset, Baseline, Dashboard 원본 상태 데이터와 두 Agent 수용 보고서는 HEAD와 바이트 동일. Week 3/4 미착수·실험 0건·선정 가설 3개 유지.
- `git diff --check`: 통과.

브라우저 검증 도구와 브라우저는 `/tmp`에 설치했으며 프로젝트 의존성에는 추가하지 않았다. 스크린샷은 `/tmp/careerfolio-desktop.png`, `/tmp/careerfolio-mobile.png`. 미리보기는 로컬 3100 포트에서 실행했다. 배포·외부 게시 작업은 수행하지 않았다.

## 운영·한계

개인 Dataset과 해석 표시 데이터는 빌드 시 읽으므로 수정 후 재빌드한다. 공고는 동적 서버 요청이며 외부 네트워크가 필요하다. 통합 데이터의 제목 키워드는 자격 판정이 아니고 최신 API 노출도 지원 마감을 보장하지 않으므로 원문 확인을 안내한다. 체크는 브라우저별 저장이며 서버 쓰기는 없다.

구현 참고: [Greenhouse Job Board API](https://docs.greenhouse.io/job-board.html). 운영 설명은 [Dashboard 안내](../dashboard/README.md).
