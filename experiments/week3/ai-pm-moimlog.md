# EX-W3-01 — PM: MOIMLOG 기획·개발 사례 회고

상태: 기존 수행 프로젝트의 회고 초안 · 사용자 검토 및 평가 미완료. W2-H1의 제품 경험과 연결하되 현재 직무명은 PM. 질문: 실제 문제 발견과 제품 기획·개발은 나에게 어떤 경험이었고 PM 진로와 어떻게 연결되는가?

## 사용자 자기보고 — 배경·문제·과정

교회 대학부 순장으로서 삶과 말씀 나눔을 손으로 기록하느라 상대방의 이야기에 온전히 집중하기 어려웠고, 본인이 이야기할 때는 다른 지체에게 기록을 부탁해야 했다. 눈을 마주보고 대화하면 집중·공감·깊이 있는 나눔에 도움이 될 것이라는 **사용자의 문제의식과 가설**과 기록의 물리적 불편을 함께 고려했다. 효과를 별도 검증한 사실은 없다.

보고서 작성을 자동화하기 위해 초기 MVP(최소 기능 제품)에서 네이버 클로바로 녹음·음성 전사(STT)를 하고, 전사 내용을 ChatGPT에 전달해 정해진 순보고서 양식의 DOCX로 변환했다. 사용자가 직접 내용을 수정해 보고서를 완성해 보았다. 이후 웹 형태로 발전시키고 Groq API를 활용해 앱 형태까지 구현했다. 약 5,000원 수준의 비용을 고려했으며 산정 범위와 실제 전체 운영 비용은 미확인이다. 2026년 12월까지 UI와 서비스를 완성하고 App Store에 출시하는 것은 목표이며 출시 완료는 아니다.

## PM 활동에 대한 Agent 분석

자신이 겪은 문제를 정의하고, 기존 도구를 조합해 보고서 완성 흐름을 시험한 뒤 웹·앱으로 발전시킨 경험은 문제 정의·MVP·제품 구현과 연결된다. 5,000원 수준을 고려한 점은 비용 제약의 초기 단서다. 기능별 우선순위, 대안 비교, 동의와 비용 설계의 실제 결정 이유는 추가 확인한다. 공감 향상이나 반복 사용을 입증했다고 해석하지 않는다.
