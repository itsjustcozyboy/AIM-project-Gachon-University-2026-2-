# Week 3 — TEST: 생각을 실제 행동으로 검증

상태: 진행 중 · MOIMLOG 기획·개발 경험은 사용자 확인, 세 실험의 평가·정리는 미완료. 계획 시간은 남은 정리·실험의 잠정치이며 사용자와 조정한다.

1주차 자기보고 경험과 강점·가치관 가설, 2주차의 LOW confidence 가설을 실제 활동에 연결한다. 기존 미채택 초안은 이력으로 유지한다.

|---|---|---|---|---|

## 체크리스트

- [x] 기존 자료 검토 및 세 실험 초기 문서 준비
- [x] MOIMLOG 직접 기획·개발 경험 사용자 확인
- [ ] 각 실험 사전 평가와 사용자 선택 기록
- [ ] PM: 기여와 구현 상태 확인, 제품 판단 및 결과 기록
- [ ] Strategy: 대상 선택, 자료 조사, 판단과 제안서 작성
- [ ] HCI: 앱·질문 선택, 동의 후 2–3명 테스트, 분석과 보고서 작성
- [ ] 세 실험 사후 평가 및 [비교·4주차 준비](comparison.md)

각 가설에 서로 다른 실제 과제를 연결하고, Agent는 과제 단계와 체크리스트를 만들며 수행 중 피드백·리뷰·수정안을 제공한다. 일반적인 흐름은 사전 기록 → 설계 → 직접 수행 → AI 피드백 → 사후 기록 → 다음 행동이다. MOIMLOG는 이미 수행한 경험이므로 당시 기대를 회상해 기록하되 실시간 사전 측정으로 표시하지 않는다. [공통 평가 양식](evaluation.md)을 각 실험에 복사한다. 관찰 사실·발언·해석·가설을 구분한다. 세 결과가 나오기 전 비교는 빈 틀로 유지한다.

범위: K-뷰티는 소비자 시장 사례이므로 W2-H3의 B2B 대 B2C 비교를 단독 검증하지 못한다. 금융 앱 사용성 연구는 W2-H4의 논문 비평·Human-AI 연구를 직접 검증하지 않는다. MOIMLOG도 기존 B2B 가설 전체를 대표하지 않는다.
