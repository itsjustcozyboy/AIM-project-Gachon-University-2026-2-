# 공통 사전·사후 평가

사용자 직접 입력. 각 점수 1–10, 난이도는 높을수록 어려움. MOIMLOG·K-뷰티 사전 평가는 시작 당시 기대에 대한 **현재의 회상**으로 실시간 측정이 아니다. HCI는 본인 분석 수행 전후를 구분한다. 미입력 값의 차이를 계산하지 않는다.

| 항목 | 사전 점수 / 이유·예상 | 사후 점수 / 이유·구체적 경험 |
|---|---|---|
| 흥미 | 미입력 | 미입력 |
| 몰입 | 미입력 | 미입력 |
| 난이도 | 미입력 | 미입력 |
| 역량 적합도 | 미입력 | 미입력 |

각 과제에 표를 복사하거나 연결해 작성한다. 흥미로웠던 순간, 어려움·보완 역량, 기대와 실제의 차이, 진로 관심·재수행 의향, 추가 확인점 및 실제 활동·기간·도움도 기록한다. 점수는 객관적 능력이나 취업 가능성이 아니다.
