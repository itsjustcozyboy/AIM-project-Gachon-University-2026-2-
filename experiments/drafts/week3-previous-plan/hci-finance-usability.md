# EX-W3-03 — HCI: 금융 앱 사용성 연구

상태: 준비 중 · 앱·연구 질문 미선택 · 참여자 모집과 테스트 미완료. 연결 W2-H4(부분적); 예상 3–4시간 + 모집(잠정).

HCI(사람과 컴퓨터의 상호작용) 연구의 관찰·분석 활동을 경험한다. 결과물: [사용성 연구 보고서](../results/week3-hci-report.md), 1–2쪽 목표. 일반 금융 앱 사용성만으로 Human-AI 연구나 논문 비평 선호를 확정할 수 없다.

## 사전 평가
[공통 양식](evaluation.md): 미입력.

## 선택과 설계
사용자가 공개 화면 또는 가상 화면으로 볼 앱과 구체적 질문을 선택한다. 같은 화면을 각 참여자 2–3명에게 보여 주고 아래 과제를 선택한 앱에 맞게 문구만 구체화한다. 예상 과제: ① 특정 기능이 어디 있는지 찾기 ② 제시된 정보의 의미 설명하기 ③ 가상 상황에서 결정을 위해 추가로 확인할 정보 말하기. 실제 가입·송금·거래는 하지 않는다.

## 진행 스크립트
“앱을 평가하는 것이지 참여자를 평가하는 것이 아닙니다. 언제든 중단하거나 답변을 건너뛸 수 있습니다. 개인정보는 알려주지 마세요. 익명으로 메모해도 괜찮으신가요?” 동의 확인 후 “평소처럼 화면을 보며 생각을 말씀해주세요. 제가 힌트를 주기 전까지 직접 찾아주세요.” 각 과제를 같은 순서로 제시하고 힌트나 중단을 기록한다. 종료 후 감사를 전한다. 녹음은 기본적으로 하지 않는다.

테스트 전: 금융 앱 사용 경험이 어느 정도인가요? 이 과제에 얼마나 자신 있나요(1–5)? 테스트 후: 가장 헷갈린 지점은? 정보를 얼마나 이해하고 안심했나요(각 1–5)? 바꾸고 싶은 점은?

## 관찰 양식 — 참여자별 반복
- 익명 ID P1/P2/P3 · 날짜 · 동의 여부 · 사용 경험: 미입력
- 과제 / 행동 순서 / 멈춘 곳 / 완료·중단 / 힌트: 미입력
- 참여자 발언(가능한 그대로): 미입력
- 관찰자의 해석(사실과 분리): 미입력
- 사전·사후 답변 / 개선 아이디어: 미입력

계좌번호·잔액 등 개인 금융정보는 수집하지 않는다. 동의하지 않으면 테스트하지 않는다. 2–3명의 소규모 탐색 결과는 전체 사용자에게 일반화하지 않는다.

성공 기준(잠정): 동일 과제의 관찰·발언·해석을 구분하고, 발견 근거에 연결된 개선 화면을 제안한다. 실제 선택·진행·AI 피드백: 미입력.
