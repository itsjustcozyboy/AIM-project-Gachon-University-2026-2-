# Career Evaluation Framework

| Criterion | Weight |
|---|---:|
| Interest Fit | 15 |
| Strength Fit | 15 |
| Value Fit | 15 |
| Work Environment Fit | 10 |
| Existing Evidence | 10 |
| Market Opportunity | 10 |
| Growth Potential | 10 |
| Skill Acquisition Feasibility | 5 |
| Global Opportunity | 5 |
| AI Leverage | 5 |
| Total | 100 |

각 기준은 0~10으로 평가하고 가중점수 = (Score / 10) × Weight로 계산한다.
각 평가마다 Score, Evidence, Reason, Confidence(HIGH / MEDIUM / LOW)를 함께 기록한다.
자료가 없으면 Score는 null, Evidence/Reason은 UNKNOWN 및 부족한 자료를 명시한다. Confidence는 LOW로 표시한다.
미평가 항목이 있으면 전체 점수는 null로 유지한다. 확인된 항목의 부분합과 평가된 가중치 범위를 별도로 표시하며 100점으로 재환산하지 않는다.

HIGH: 반복된 직접 수행 결과와 여러 독립 근거가 일치.
MEDIUM: 일부 직접 근거가 있으나 검증 범위가 제한됨.
LOW: 자기보고·간접 추론 위주이거나 반대 근거·자료가 부족함.

각 후보에 적합 근거, 부적합 가능성, 반대 증거와 출처·확인일을 연결한다. 초기 가설의 신뢰도는 아직 평가하지 않았으므로 UNKNOWN이다.
